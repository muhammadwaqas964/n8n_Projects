# n8n Projects — AI DevOps Agent

An AI-powered automation system built with n8n that handles Fiverr client 
management for DevOps and Cloud engineering projects.

## What This Does
- Qualifies Fiverr clients automatically using AI
- Gathers complete project requirements through conversation
- Generates step-by-step DevOps implementation plans
- Sends notifications to Discord when project plan is ready

## Tech Stack
- n8n (workflow automation)
- Google Gemini (AI brain)
- Discord Webhooks (notifications)
- GitHub (project tracking)
